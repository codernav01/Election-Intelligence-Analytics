# 🗳️ Election Intelligence Analytics — Tamil Nadu Assembly Elections

## 📌 Project Overview

**Election Intelligence Analytics** is an end-to-end **Data Analytics & Business Intelligence project** focused on analyzing constituency-level election data from the **2021 and 2026 Tamil Nadu Assembly Elections**.

The project transforms raw election datasets into **validated, analysis-ready data**, performs exploratory and comparative analysis using **Python and SQL**, and presents the resulting insights through an **interactive Power BI dashboard**.

The core focus is on identifying **regional shifts, constituency-level winner changes, and vote-share patterns** and converting these findings into structured, evidence-based election stories.

---

## 🎯 Project Objectives

The project aims to:

- Analyze electoral patterns across the 2021 and 2026 elections
- Clean, validate, and structure raw election datasets
- Compare constituency-level electoral outcomes
- Identify regional variations and changes in electoral performance
- Analyze party-wise and constituency-level vote shares
- Identify constituencies where the winning party changed
- Build a reusable SQL analytics layer for reporting and BI
- Convert analytical findings into clear, data-driven election stories
- Present the final analysis through an interactive Power BI dashboard

---

## 📂 Datasets Used

The project uses three core datasets containing election results and constituency reference information.

| Dataset | Description | Purpose |
|---|---|---|
| **e1.csv** | 2021 Tamil Nadu Assembly Election Results | Historical election analysis |
| **e2.xlsx** | 2026 Tamil Nadu Assembly Election Results | Comparative election analysis |
| **e3.xlsx** | Constituency Master / Reference Data | District, region, reservation, and constituency mapping |

### Primary Analytical Key

`AC Number`

The datasets are connected using constituency-level identifiers to enable comparison across election years and integration with constituency reference information.

## 🔍 Key Research Questions

The project is structured around three primary research questions that drive the analytical and storytelling process.

### 1️⃣ Geographic Story

**Where did the electoral landscape change across Tamil Nadu's regions?**

Analyzes regional differences in electoral performance and identifies areas where significant changes occurred between 2021 and 2026.

### 2️⃣ Flip Story

**Which constituencies changed their winning party between 2021 and 2026?**

Identifies constituencies where the winning party changed and examines the distribution of these electoral flips across Tamil Nadu.

### 3️⃣ Vote Share Story

**How did party vote share vary across regions and constituencies?**

Compares party-wise vote share across constituencies and regions to identify changes in electoral strength and competitive patterns.
